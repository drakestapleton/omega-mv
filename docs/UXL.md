# UXL checks

One line per machine. The same table is at the top of the README. Paste one line. It is safe to run again: the package install accepts what is already present, `omega-mv` is removed, then the clone and the full run start over. The run writes `omega-mv/uxl-run.log` and its own `uxl-run-<host>-<UTC>.log`.

| Machine | Line | Note |
| --- | --- | --- |
| x86-64 Linux (Debian/Ubuntu) | `cd "$HOME" && sudo apt-get update && sudo DEBIAN_FRONTEND=noninteractive apt-get install -y git ca-certificates python3 qemu-user-static binfmt-support spirv-tools mesa-vulkan-drivers ocl-icd-libopencl1 && rm -rf omega-mv && git clone -b uxl/all-stages https://interplane.io/drakestapleton/omega-mv.git && cd omega-mv && ./uxl-run.sh > uxl-run.log 2>&1` | Installs qemu-user-static, binfmt-support, spirv-tools, python3, mesa-vulkan-drivers, and ocl-icd-libopencl1. qemu-user-static is what runs the AArch64 `omc`. On a normal Ubuntu or Debian install that package registers the interpreter. |
| arm64 Linux (Debian/Ubuntu) | `cd "$HOME" && sudo apt-get update && sudo DEBIAN_FRONTEND=noninteractive apt-get install -y git ca-certificates python3 spirv-tools mesa-vulkan-drivers ocl-icd-libopencl1 && rm -rf omega-mv && git clone -b uxl/all-stages https://interplane.io/drakestapleton/omega-mv.git && cd omega-mv && ./uxl-run.sh > uxl-run.log 2>&1` | No qemu. `omc` is an AArch64 Linux binary and runs natively. |
| macOS | `brew install git python spirv-tools && cd "$HOME" && rm -rf omega-mv && git clone -b uxl/all-stages https://interplane.io/drakestapleton/omega-mv.git && cd omega-mv && ./uxl-run.sh > uxl-run.log 2>&1` | Homebrew installs git, Python 3, and spirv-tools. omc stages are NOT_RUN unless a Linux VM is available: `omc` is an AArch64 Linux binary and macOS has no binfmt. |
| Windows PowerShell (native) | `winget install -e --id Git.Git --accept-package-agreements --accept-source-agreements --disable-interactivity; winget install -e --id Python.Python.3.12 --accept-package-agreements --accept-source-agreements --disable-interactivity; $env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User'); Set-Location $env:USERPROFILE; if (Test-Path omega-mv) { Remove-Item -Recurse -Force omega-mv }; git clone -b uxl/all-stages https://interplane.io/drakestapleton/omega-mv.git; Set-Location omega-mv; powershell -ExecutionPolicy Bypass -File .\uxl-run.ps1 *> uxl-run.log` | winget installs Git and Python 3.12 when they are missing, then clones and runs `.\uxl-run.ps1`. `omc` cannot exec here. The script prints the WSL rerun line, and the omc stages are NOT_RUN. |
| Windows WSL2 Ubuntu | `wsl -d Ubuntu -- bash -lc 'cd "$HOME" && sudo apt-get update && sudo DEBIAN_FRONTEND=noninteractive apt-get install -y git ca-certificates python3 qemu-user-static binfmt-support spirv-tools mesa-vulkan-drivers ocl-icd-libopencl1 && rm -rf omega-mv && git clone -b uxl/all-stages https://interplane.io/drakestapleton/omega-mv.git && cd omega-mv && ./uxl-run.sh > uxl-run.log 2>&1'` | The x86-64 Linux line, run inside WSL2 Ubuntu. Paste this in Windows PowerShell. The log is `~/omega-mv/uxl-run.log` in that Ubuntu home. |

Same work, without the wrapper: `python3 tools/uxl/run_all.py` (Windows: `py tools\uxl\run_all.py`). Python 3.8 or newer, standard library only.

The run prints the OS, architecture, Python, `git core.autocrlf`, whether `qemu-aarch64` binfmt can run `seed/out/omc`, and whether an Intel GPU and OpenCL runtime are present. It does not require the GPU. Level 1 checks the published 65-file record under `tools/uxl/level1/` (path comparison uses `as_posix()`). Level 2 rebuilds the launcher and the 18 gfx942 kernels with `seed/out/omc` and compares them to `gpu/amd/card.tsv`. Those receipt hashes are the ones in the brief: `launch-x86` and `vadd` match Zenodo record 10.5281/zenodo.24237047. On x86 the arm64-only `trace.c` instruments are skipped, not passed. `omc` is the pinned AArch64 binary `b6129ed51e07dd8ef7f33e78fdff99d6c4d914e3bccdaf8b344043b95017d4f2` (read from `seed/out/omc.sha256`). It runs natively on arm64 Linux and through qemu-aarch64 binfmt on x86 Linux. Without that, Level 2 is skipped and the log says how to enable it.

The SPIR-V stage runs `OMC=seed/out/omc sh gpu/spirv/check.sh` (spirv-val, mutants, host conform) and streams each line. It skips only when `spirv-val` or `omc` cannot run, and the skip line says how to install `spirv-tools` or `qemu-user-static`. The RMSNorm stage reads `gpu/spirv/intel-rmsnorm.tsv` and runs every row. Exit 0 is PASS, exit 2 is NOT_RUN (prerequisite missing, or `omc` cannot execute). Anything else, after `omc` has run, is FAIL. NOT_RUN is not a pass. On native Windows, `uxl-run.ps1` prints one line first: omc-dependent stages need WSL2 (Ubuntu + qemu-user-static), with the `wsl` one-liner that reruns `./uxl-run.sh` there. The reference sha256 is `144c89820d5d005af741dfcace8f9882bae481d72f1745aef36b5014cbaadb46`. The Intel OpenCL stage reads `gpu/spirv/intel-opencl.tsv` and runs `vadd`, `fsum16`, and `gemm16` the same way (exit 0 is a bit-exact match, exit 2 is NOT_RUN). Each kernel has an `opencl-intel` row and a `vulkan` row. The gemm16 reference sha256 is `d1e02b7d8dd06cd84ee45294b0525000cf7c61e6f6fa32bfa81d3719e47a6987`. Host conform for the same kernels also runs inside `gpu/spirv/check.sh`.

The evidence stage fetches `https://zenodo.org/api/records/24237047`, downloads each file, and checks the checksum the API published. There is no evidence archive on that record. Offline, the stage skips and says why. The last table is PASS, FAIL, SKIP, NOT_RUN, or MISSING per step. Skip, NOT_RUN, and MISSING are never passes. The process exits 0 only when nothing failed. `--evidence URL` overrides the Zenodo API URL.
