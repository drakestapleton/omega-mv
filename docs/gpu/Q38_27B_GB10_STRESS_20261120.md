# Spark GB10 Qwen decode stress test

Omega public main `371a882a5` on physical GB10. The November 19 night and November 20 morning receipts both used `c9fe0f228`. All three used the same benchmark source, physics revision and seed compiler. The merged build has different test binaries and GPU archive. It links Omega’s GPU library. The separate CUDApp landing is outside that link.

The workload uses seeded weights, the dimensions of the 27B model, three GDN layers, one attention layer at head dimension 256, and the full 248,320-entry output vocabulary. Decode times use chip timestamps. Serving latency, prefill and time to first generated token were outside this workload.

## Qualification

Graph 22/22 and stroke 71/71. All four tested heads had bit-identical logits to the single-head reference. Graph mutants 1–4 and stroke mutant 5 were detected. Both eight-stream token comparisons matched 8/8.
