# tools/gate-anchors.txt: the gate-integrity files of OMEGA-GATE-ANCHOR (tools/gate_anchor.sh).
# One path per line, relative to the repository root; a line ending in '/' stands for the paths under
# that folder. '#' starts a comment line. A change to a listed path against the base ref prints
# GATE-ANCHOR CHANGED <path> and makes the head BLOCKED_OPERATOR [ctl:OMEGA-GATE-ANCHOR/edited].
# The check reads this list at the base ref, at the merge base and at HEAD, so dropping a line here
# is reported as a change to the dropped path and to this file [ctl:OMEGA-GATE-ANCHOR/list-entry-dropped].
# What is listed is what is checked: a gate-integrity file missing from here is not anchored. Owners
# send their paths to the lane that keeps this list; the list names the files the kernel fold's gates,
# the always-run gates and the gate runners trust, not every gate script of the repository.
